# cocoabeans.github.io

Kevin Ross's portfolio of apps, published with GitHub Pages at https://cocoabeans.github.io/.

It's a single self-contained page (`index.html`) with app icons in `media/`. There's no build step: edit the HTML and push to `main`.

Other pages on this domain live in their own repositories and keep their own paths:

- `/mimamori/` from [CocoaBeans/mimamori](https://github.com/CocoaBeans/mimamori)
- `/apps/` (Sesh Time and MetaSort support pages) from [CocoaBeans/apps](https://github.com/CocoaBeans/apps)
